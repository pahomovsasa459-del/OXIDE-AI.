# OXIDE AI

Стартовый Android-проект для голосового помощника.

## Версия 0.1
- Интерфейс приложения.
- Запрос разрешения на микрофон.
- Распознавание одной русской голосовой команды.
- Тестовые ответы на команды «стоп», «дерево», «камень», «ресурсы».

## Пока не реализовано
- Захват изображения игры и компьютерное зрение.
- Поиск игровых объектов.
- Автоматическое управление персонажем и сбор ресурсов.

GitHub Actions собирает тестовый debug APK при push в main или вручную через Actions.
